Egatari（絵語り）

伝える人すべてのための、1 つのファイル。

Egatari は、スライド・台本・音声・本を 1 つの HTML ファイルにまとめる形式です。ブラウザで再生でき、生成 AI で作成・修正できます。

編集アプリを開く サンプルを見る

月の満ち欠け.ega.html

教育者へ

台本と音声を備えた教材の形式

ステップで順に表示し、台本の音声と字幕が付きます。LMS（SCORM）にも登録できます。学習者は Egatari Viewer で開くと、本の形で読み、ハイライトを引き、暗記のために隠せます。ハイライトは学習者の端末の中だけに保存されます。

表現者へ

発表の機能を備えた HTML

HTML の表現をそのまま使用できます。図はステップで動き、動画にも書き出せます。ファイルの中にリンクを作成でき、本の形にもなります。

技術者へ

スライドのコンパイラ

原稿を品質チェックで検査し、プレーヤーを同梱した 1 つのファイルにビルドします。パーツはバージョンとハッシュで固定します。

<!-- moon-phases/deck.html -->
<section class="slide">
  <h2>見える形は、2 つの半分の重なり</h2>
  <svg viewBox="0 0 1180 420">…</svg>
</section>

$ npx egatari check moon-phases/deck.html
  エラー 0　警告 0
$ npx egatari build moon-phases/deck.html \
    --portable
  → 月の満ち欠け.ega.html

生成 AI で作成し、品質チェックで修正する

対話型の生成 AI（ChatGPT・Gemini・Claude など）に題材を伝えると、Egatari ファイルの原稿を作成します。品質チェックが文字のはみ出し・小さすぎる文字・色のコントラスト・画像の代替テキストを検査し、AI への修正依頼の文を作成します。

パーツが増え、表現の幅が広がる

新しい図や動きは、パーツとしてパーツライブラリに取り込まれます。誰かが生成 AI で作成した表現を、次の人がそのまま使用できます。Egatari の最初のパーツも、研究発表のスライドから取り込んだものです。

55パーツ（パーツライブラリ 2.15.0）

開かれた形式

Egatari は、特定のアプリに縛られないファイル形式です。仕様は誰でも読めて（CC BY 4.0）、どのツールからでも作成できます。

  • 仕様（Egatari 1.0）
  • GitHub

利用方法

  1. 編集アプリ（インストール不要）

    Chrome か Edge で studio.egatari.org を開き、その場で作成します。

  2. 生成 AI

    対話型 AI や AI エージェント（Claude Code・Codex）に Egatari のスキルを追加すると、Egatari ファイルを作成できます。

  3. コマンドライン

    npx egatari new mytalk --lang ja
npx egatari dev mytalk/deck.html

学習者は Egatari Viewer で

viewer.egatari.org で Egatari ファイルを開きます。ホーム画面に追加すると、ネットワークがなくても開けます。ハイライトと最近開いたファイルは、学習者の端末の中だけに保存されます。
