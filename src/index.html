Egatari 1.0 の仕様は作業中の草案です。仕様を読む

Egatari
サンプル 仕様 GitHub English

絵が語り、人へ伝える。

伝える人すべてのための、1 つのファイル。

編集アプリを開く サンプルを見る

01

1 つのファイルに、全部入る

スライド・台本・音声・本を、1 つの HTML ファイル（.ega.html）にまとめます。ブラウザで開けばそのまま再生でき、編集アプリ（Egatari Studio）で開けば直せます。メールで送る、校内のサーバーに置く、LMS に載せる（SCORM）。どれも、そのファイル 1 つです。

02

話す順に、見せる

説明する順に、図や式を 1 つずつ出します（ステップ）。台本を付ければ、読み上げの音声と字幕が付き、動画にも書き出せます。

03

AI が書き、品質チェックが直す

チャットの AI に題材を伝えると、教材の原稿ができます。品質チェックが、文字のはみ出し・小さすぎる字・色のコントラスト・画像の代替テキストを調べ、直す依頼の文まで作ります。

04

学習者の手元で、読み返す

学習者はスマートフォンやタブレットで、自分のペースで読み返せます。本の形で読む、ハイライトを引く、暗記のために隠す。引いたハイライトはその端末の中だけに残り、ファイルにも、どこにも送られません。

  • Egatari Viewer を開く

05

教育・ビジネス・生活

  • 教育 授業・講義・校内研修
  • ビジネス 報告・提案・社内研修
  • 生活 お知らせ・手引き・啓発

06

開かれた形式

Egatari は、特定のアプリに縛られないファイル形式です。仕様は誰でも読めて（CC BY 4.0）、どの道具からでも作れます。

  • 仕様（Egatari 1.0）
  • GitHub

07

始め方

  1. 編集アプリ（インストール不要）

    Chrome か Edge で studio.egatari.org を開き、その場で作ります。

  2. チャットの AI と

    Claude・Codex 用のスキルを入れると、Egatari ファイルを作れます。

  3. コマンドライン

    npx egatari new mytalk --lang ja
npx egatari dev mytalk/deck.html
